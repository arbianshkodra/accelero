Consuming the /status Endpoint in Accelero
1. Get Status of All Deployments
curl -X GET http://localhost:8000/status -H "X-API-KEY: your_api_key"

This returns an array of all deployment statuses.

2. Get Status of a Specific Deployment
curl -X GET "http://localhost:8000/status?id=1680456789012345" -H "X-API-KEY: your_api_key"

Response Format
The response will be a JSON object (for a specific ID) or array of objects (for all deployments) with this structure:
{
  "request_id": "1680456789012345",
  "service_name": "my-service",
  "status": "completed", 
  "created_at": "2025-04-02T19:45:32.123Z",
  "completed_at": "2025-04-02T19:46:12.456Z", 
  "error_message": "",
  "image_tag": "v1.2.3"
}

Possible status values:
"pending": Deployment is queued
"in_progress": Deployment is being processed
"completed": Deployment completed successfully
"failed": Deployment failed
"rolled_back": Deployment failed and was rolled back

Integration Example
# Submit deployment webhook
RESPONSE=$(curl -s -X POST http://localhost:8000/webhook \
  -H "Content-Type: application/json" \
  -H "X-API-KEY: your_api_key" \
  -d '{"text": "New Docker image has been pushed"}')

# Extract request_id
REQUEST_ID=$(echo $RESPONSE | jq -r '.request_id')

# Poll status until deployment completes
while true; do
  STATUS=$(curl -s -X GET "http://localhost:8000/status?id=$REQUEST_ID" \
    -H "X-API-KEY: your_api_key" | jq -r '.status')
  
  if [[ "$STATUS" == "completed" ]]; then
    echo "Deployment completed successfully"
    break
  elif [[ "$STATUS" == "failed" || "$STATUS" == "rolled_back" ]]; then
    echo "Deployment failed"
    exit 1
  fi
  
  echo "Deployment in progress... ($STATUS)"
  sleep 5
done
